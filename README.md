# Google Chrome Sidebar Extension 

### Installation Instructions

1. Clone repo or download the project
2. Change the iframe src URL to your local or remote project in sidepanel.html
3. Open Chrome and go to `chrome://extensions/`.
4. Enable “Developer mode” (toggle in the top-right corner).
5. Click “Load unpacked” and select your extension folder.
6. The extension will be loaded, and you can open the side panel via the extension icon.
